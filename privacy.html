Container Inspector Privacy Policy

Last updated: September 25, 2026

Container Inspector is a limited internal educational application intended for a small group of professionals studying shipping container inspection and repair-related material.

Data We Process

The application uses an automatically generated anonymous account identifier to allow training progress to be stored and restored.

The application may store educational activity such as:

  • questions answered;
  • answer results;
  • learning progress and mastery status;
  • practice-session information.

This information is used only to provide the application's learning and progress-tracking functionality.

Personal Information

Container Inspector does not require users to provide a name, email address, phone number, home address, precise location, payment information, contacts, photos, or social-media information.

The application does not use advertising and does not track users across third-party apps or websites.

Infrastructure

Application data is processed using cloud infrastructure required to operate the service. Technical connection and security information, such as network or server logs, may be processed by the hosting provider for security, reliability and service operation.

Use of Data

Data is used only to operate the application, maintain training progress, provide educational functionality, secure the service and troubleshoot technical problems.

Data is not sold and is not used for advertising or behavioral profiling.

Intended Audience

This application is intended for limited internal educational use and is not intended for general public or commercial distribution.

Contact

For privacy questions or requests concerning Container Inspector, please use the contact information provided on the Container Inspector Support page.
